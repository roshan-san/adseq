PROJECT PHASE II - SLIDE CONTENT
Recurrent Neural Networks vs. Lag-Feature FNN for Forecasting a Full-Scale Anaerobic Digester

SLIDE 1 - ABSTRACT
- Anaerobic digestion turns organic waste into biogas; forecasting it aids plant planning
- Base paper (Long et al., 2026) uses an FNN on hand-picked lag features
- We compare Vanilla RNN, GRU and LSTM against this lag-feature FNN
- Public daily data from the Muscatine, Iowa co-digestion plant
- Same split, features and tuning budget for every model
- Best model (RNN): R² = 0.742 vs. 0.659 for the base-paper FNN

SLIDE 2 - PROBLEM STATEMENT
- Biogas output depends on feed, temperature and chemistry over past days
- Lag-feature FNNs only see hand-chosen memory lengths
- Prior studies often use lab-scale or private data
- Random splits and untuned baselines make comparisons unreliable
- Goal: test whether recurrent models beat the lag-feature FNN
- Under a fair, leakage-free and reproducible protocol

SLIDE 3 - LITERATURE SURVEY
- Nair 2016, Beltramo 2019: ANN/FNN biogas models at lab or farm scale
- Seo 2021, Jeong 2021: RNN/deep models match or beat process models
- Salamattalab 2024, Shen 2024: LSTMs outperform non-temporal models at large scale
- Long 2026 (base paper): lag-feature FNN on commercial data, features hand-made
- Schroer & Just 2024: public full-scale Muscatine data, non-recurrent models
- Gap: no fair, equal-budget RNN vs. lag-FNN comparison on public full-scale data

SLIDE 4 - SYSTEM ARCHITECTURE
- Muscatine daily data -> cleaning (invalid readings, short gaps)
- Feature engineering: calendar, lag and rolling features
- Chronological train / validation / test split; scaler fit on training only
- Branch A: lag features -> FNN baselines (base-paper, tuned)
- Branch B: 15-day windows -> RNN, GRU, LSTM (and Window-FNN)
- Equal-budget W&B tuning -> multi-seed evaluation -> best model

SLIDE 5 - UPDATED WORK (AFTER PHASE I)
- Switched to the public Muscatine dataset (base-paper data not available)
- Full Python/PyTorch pipeline: data, training, tuning, evaluation
- Bayesian tuning (W&B Sweeps), 40 runs per model; 10 seeds each
- Test year 2022-04 to 2023-03; min-max scaling as in the base paper
- Test RMSE (ft³/min): RNN 19.2, GRU 19.9, tuned FNN 21.6, base FNN 22.1, LSTM 22.9
- RNN and GRU significantly beat both FNNs; Window-FNN (27.4) shows recurrence matters

SLIDE 6 - CONCLUSION
- Built a reproducible forecasting pipeline on public full-scale data
- Fair, leakage-free, equal-budget comparison of RNN, GRU, LSTM and FNNs
- Vanilla RNN best (R² = 0.742), GRU close behind (0.725)
- Both significantly better than the base-paper FNN (0.659)
- LSTM (0.631) no better than the FNNs
- Future work: multi-day forecasts, more plants, CH4/H2S targets
