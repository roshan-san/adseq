PROJECT PHASE II - SLIDE CONTENT
Title: Recurrent Neural Networks vs. Lag-Feature FNN for Forecasting a Full-Scale Anaerobic Digester
Results from runs/main (full run finished 2026-11-15 17:50).

======================================================================
SLIDE 1 - ABSTRACT
======================================================================
- Anaerobic digestion (AD) turns organic waste into biogas. Its output depends on
  past operating conditions, so accurate forecasting helps plant monitoring and planning.
- The base paper (Long et al., 2026) predicts AD output with a feed-forward neural
  network (FNN) on hand-picked lag and rolling-statistic features.
- We compare Vanilla RNN, GRU and LSTM models, which learn temporal patterns directly
  from input sequences, against this lag-feature FNN.
- The study uses public daily data from a full-scale municipal co-digestion plant
  (Muscatine, Iowa, USA) to forecast daily biogas production.
- All models get the same data split, the same features and the same tuning budget.
  They are scored with RMSE, MAE and R² over repeated runs and checked with a
  statistical significance test.
- The best recurrent model, Vanilla RNN, reached R² = 0.667, compared with R² = 0.658
  for the base-paper FNN; the difference is not statistically significant.

======================================================================
SLIDE 2 - PROBLEM STATEMENT
======================================================================
- Biogas production in a full-scale digester changes with feed load, temperature and
  process chemistry, and today's output depends on conditions over previous days.
- Existing lag-feature FNN models only see the past through memory lengths chosen by
  hand (fixed lag days and rolling windows), so patterns outside these windows are missed.
- Most AD forecasting studies use lab-scale or private data, random train/test splits
  that leak information, or untuned baselines, which makes model comparisons unreliable.
- Problem: decide whether recurrent models (RNN, GRU, LSTM) forecast daily biogas at a
  full-scale plant better than the lag-feature FNN under a fair, leakage-free and
  reproducible protocol.

SLIDE 5 - UPDATED WORK (FURTHER WORK CARRIED OUT AFTER PHASE I)
======================================================================
--- 5a. Phase I -> Phase II changes ---
- Dataset: the base paper's commercial data was not publicly available, so we moved to
  the public Muscatine full-scale co-digestion dataset.
- Target: daily biogas production (the public data has no CH4 or H2S measurements).
- Implementation: the full pipeline was built in Python and PyTorch, from data loading
  and preprocessing through training, tuning and evaluation.
- Tuning: Bayesian hyperparameter search with Weights & Biases Sweeps, with the same
  budget for every model.
- Evaluation: repeated runs with different random seeds, plus a statistical test to
  check whether differences between models are real.

--- 5b. Experimental protocol ---
- Chronological train / validation / test split; the test set covers the final year so
  it includes a full seasonal cycle.
- Scaling and features use past data only, so no information leaks from the future.
- Every model is scored on the same test days with the same metrics.

--- 5c. Models compared ---
- Persistence: tomorrow's biogas equals today's (sanity baseline).
- Base-paper FNN: reproduced as published.
- Tuned FNN: same FNN, tuned with the same budget as the recurrent models.
- Window FNN: same input window as the recurrent models but no recurrence (ablation).
- Vanilla RNN, GRU and LSTM: learn temporal dependencies from input sequences.

--- 5d. Results ---
Model            | RMSE  | MAE   | R²
Persistence      | 27.9  | 21.1  | 0.459
Base-paper FNN   | 22.1  | 15.9  | 0.658
Tuned FNN        | 23.8  | 17.3  | 0.604
Window FNN       | 34.3  | 26.8  | 0.177
Vanilla RNN      | 21.8  | 16.5  | 0.667
GRU              | 22.3  | 16.5  | 0.654
LSTM             | 25.4  | 18.8  | 0.551
(Values are mean over repeated runs on the test year; RMSE and MAE in ft³/min.)

- Vanilla RNN gave the best forecasts and GRU came close; both clearly beat the tuned
  FNN, but neither was significantly better than the base-paper FNN.
- LSTM was the weakest recurrent model and did not beat either FNN.
- Window FNN (same input window, no recurrence) did much worse, so the gain comes
  from recurrence itself, not just from seeing more past days.

======================================================================
SLIDE 6 - CONCLUSION
======================================================================
- Built a complete, reproducible forecasting pipeline for a full-scale anaerobic
  digester using public plant data.
- Compared Vanilla RNN, GRU and LSTM against the lag-feature FNN under a fair,
  leakage-free, equal-budget protocol.
- Vanilla RNN achieved the best accuracy (R² = 0.667), clearly ahead of the tuned FNN
  (R² = 0.604) and level with the base-paper FNN (R² = 0.658).
- LSTM (R² = 0.551) fell behind both FNNs, so recurrence does not help every
  architecture equally.
- Future work: multi-day-ahead forecasting, data from more plants, methane and H2S
  targets, and use in plant control decisions.
